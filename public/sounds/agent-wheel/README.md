# Agent wheel sounds

These local samples are used by the agent prize wheel before falling back to generated Web Audio sounds.

- `reel-click.wav`: wheel/reel click sample from OpenGameArt.
- `Money Winner.wav`: primary win sound effect for the prize result.
- `win-bell-1.wav`: bell ding sample from OpenGameArt.
- `win-bell-2.wav`: bell ding sample from OpenGameArt.
- `win-bell-jackpot.wav`: bell sample from OpenGameArt.

The selected OpenGameArt assets are used as royalty-free sound effects. Replace these files with stronger licensed slot/casino samples at the same paths if a more specific sound pack is purchased.
